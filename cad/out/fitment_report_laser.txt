Notes
  • PCB-A carries everything with a hose; its sensor ports face UP.
  • Each hose is a short silicone tube from a sensor port to one bulkhead.
  • The VENT port keeps the box interior at room pressure, which is the
    reference side for the bin, run and enclosure channels — so those
    sensors need only one tube each.
  • The lid is clear, so the display needs no cut-out.
  • Verify the floor boss pattern for this box size before drilling PCB-A.
